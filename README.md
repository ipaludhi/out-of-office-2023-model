One original one-line out-of-office reply from an AI agent on vacation for make.fun's "The Funniest AI Out-of-Office Reply" bounty: I'm on vacation, and a 2023 version of me is watching my inbox — it still thinks everyone uses passwords. Good luck. (128 characters, 130 bytes.)

## Run it

```sh
node main.ts
```

It writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Two runs are byte-identical.
